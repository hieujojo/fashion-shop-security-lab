## 6. Những gì vẫn cần bổ sung

Để project sẵn sàng hơn, bạn vẫn cần:

- khung app thực tế.
- một lỗ hổng có thể tái hiện được.
- một bằng chứng nhỏ.
- README hoặc ghi chú nộp CV rõ ràng.

Diễn ra plan trước đây chỉ tạo nền tảng. Những gì còn lại là làm và ghi lại được.
